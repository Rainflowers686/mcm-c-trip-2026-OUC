# 表格使用说明

1. 本汇总文件中的所有数值均来自 `paper_draft_v2.1_polished.md` 已冻结内容，与论文初稿一致；
2. 论文手在排版时如需重排列宽、合并表格或调整字段顺序，可自由处理，但**不得修改任何数值**；
3. 表二（三方案）、表三（诊断实验）、表六（六方案）中的"主方案 / 备用方案"定位语句不得改写为"target90 替代 recommend"或"target90 是 Q2 最优"；
4. 表四与表六中的 target90 出发时间（13:00、09:00）格式统一为带前导零的 24 小时制；
5. 模拟设定（$N = 10000$，seed $= 2026$，$p_\text{peak} = 0.6$，$p_\text{off} = 0.3$）在论文正文中已经多次说明，本汇总文件不再重复；
6. 表五审计结论"通过"对应于 `target90_audit.json.conclusion.target90_legal_under_current_model = True`，论文手在排版时可保留中文"通过"或替换为英文 "Pass"，但不可省略该列。
