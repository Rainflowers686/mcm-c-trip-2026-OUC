## 2. 必须修正的问题

### 2.1 `p_peak / p_off` 来源不能写成题目给定

**问题**  
初稿中部分位置将 `p_peak=0.6`、`p_off=0.3` 写成类似“题目题设”“题给参数”的表述。若原题只给出“发生拥堵时的额外延时条件分布”，没有给出堵车发生概率，那么这两个概率不能写成题目给定。

**建议改法**  
全文统一改为：

> 本文默认强扰动情景假设为 `p_peak=0.6`、`p_off=0.3`。题目给出的是发生拥堵时的额外延时条件分布，但未给出拥堵发生概率，因此本文设置该概率用于刻画五一节假日强扰动场景。

**需要同步修补的位置**  
摘要、模型假设、符号说明、问题三扰动模型、敏感性分析、附录 C。

### 2.2 问题二综合得分公式需与归一化口径一致

**问题**  
初稿中综合得分曾写为：

```latex
F = \lambda_1 \tilde Z_1 - \lambda_2 \tilde Z_2 - \lambda_3 \tilde Z_3 + \lambda_4 \tilde Z_4
```

但程序输出中的 `Z2_norm`、`Z3_norm` 已经是经过反向归一化后的 benefit-normalized 指标，即均为“越大越好”。如果公式中继续写减号，会与代码口径和结果解释不一致。

**建议改法**  
先说明 \(Z_2\)、\(Z_3\) 是成本型目标，先反向归一化：

```latex
\tilde Z_2 = \frac{Z_2^{\max}-Z_2}{Z_2^{\max}-Z_2^{\min}}, \qquad
\tilde Z_3 = \frac{Z_3^{\max}-Z_3}{Z_3^{\max}-Z_3^{\min}}
```

然后综合得分统一写为：

```latex
F = \lambda_1 \tilde Z_1 + \lambda_2 \tilde Z_2 + \lambda_3 \tilde Z_3 + \lambda_4 \tilde Z_4
```

并补一句：

> 由于四个归一化目标均已处理为“越大越好”，综合得分公式中四项均取加号。

### 2.3 target90 Day1 13:00 出发时段解释需修正

**问题**  
初稿中有“13:00–14:30 高峰尾段风险”一类表述，容易与高峰时段定义冲突。若高峰定义为 11:00–13:00，则 13:00 之后应进入 13:00–16:00 平峰段。

**建议改法**  
统一写成：

> Day1 选择 13:00 出发，避开 11:00–13:00 高峰段，主要车程落入 13:00–16:00 平峰段，因此适用平峰扰动分布。

---

### 2.4 Day1 / Day5 边界推导需统一

**问题**  
正文和附录对 Day1 起始时间曾出现不同链条，容易让人误解 Day1 为什么是 11:30 开始景区活动。

**建议改法**

Day1 统一写为：

> 7:00 从家出发，居住地至酒店 4.0 h，11:00 到达酒店，入住 0.5 h，因此 11:30 后开始景区活动。

Day5 统一写为：

> 16:30 回酒店，0.5 h 离店整备 / 取车取行李，随后 4.0 h 返家，恰好可在 21:00 前到家。

**禁止再写**  
不要再写“起床整装 1.5 h + 8:30 出发 + 4.0 h + 0.5 h = 13:00”这类与正文边界不一致的推导。
