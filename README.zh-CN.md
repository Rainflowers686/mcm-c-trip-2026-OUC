本仓库保存中国海洋大学 2026 年数学建模校赛 C 题项目，研究五一假期五日自驾游规划。

项目围绕景点选择、多目标路线规划和出行可靠性分析展开。题目、模型说明、代码、论文、结果和提交材料集中保存在仓库中，便于查阅。

## 项目状态

项目归档，集中保留题目、模型说明、代码和提交材料。

## 复现

先阅读题目与模型说明，再按源码和提交材料中的运行指引、环境说明操作。仓库中的结果属于项目产物，不代表获奖或经过独立验证。

## 项目结构

- problem/：题目资料
- model_specs/：模型说明
- src/：实现代码
- paper/、results/ 与 submission/：项目产物
